# CloneLLM

Access date: 2026-07-28.

1. Purpose: minimal Python package for creating an AI clone using RAG.
2. License/distribution: open-source GitHub package.
3. Architecture: LiteLLM and LangChain-based retrieval-augmented answering.
4. Modules: document ingestion, embeddings/retrieval, answer generation.
5. Memory model: knowledge-base retrieval.
6. Persona/style model: mimics tone/expertise through source material.
7. Retrieval: RAG core.
8. Prompt construction: retrieved personal content used to answer as clone.
9. Feedback/training: not clearly documented.
10. Telegram/channel integration: none confirmed.
11. Human behavior simulation: none.
12. Sales/support: none.
13. Multi-user/multi-tenant: no platform layer confirmed.
14. Privacy/deployment: self-hosted/local possible.
15. Strengths: simple personal RAG baseline.
16. Weaknesses: too small to replace platform.
17. Reusable: minimal RAG clone baseline.
18. Not reusable: Telegram behavior runtime.
19. Maturity: small package/prototype.
20. Sources: https://github.com/msamsami/clonellm.
