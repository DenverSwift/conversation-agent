# Supermemory

Access date: 2026-07-28.

1. Purpose: context infrastructure for AI agents with memory, RAG, profiles, connectors, and file processing.
2. License/distribution: open-source repository plus hosted API/service.
3. Architecture: ingest conversations/documents, learn memories, expose search/profile APIs.
4. Modules: Memory API, document ingestion, graph/database layer, profiles, connectors, SDKs.
5. Memory model: persistent memory with learning model and graph database according to docs.
6. Persona/style model: profiles support personalization; Matvey-style compiler not confirmed.
7. Retrieval: document search, graph traversal, profiles.
8. Prompt construction: app retrieves context and wires chat harness.
9. Feedback/training: learning model decides what/how to learn; details provider-specific.
10. Telegram/channel integration: none found.
11. Human behavior simulation: none.
12. Sales/support: can power agents, not a CRM platform.
13. Multi-user/multi-tenant: team/company-brain positioning.
14. Privacy/deployment: hosted and self-run claims require review.
15. Strengths: broad context API.
16. Weaknesses: possible SaaS dependency.
17. Reusable: memory API and retrieval patterns.
18. Not reusable: end-to-end Telegram behavior agent.
19. Maturity: active, adoption risk to review.
20. Sources: https://github.com/supermemoryai/supermemory, https://supermemory.ai/docs, https://supermemory.ai/docs/overview/what-is-supermemory, https://supermemory.ai/docs/concepts/how-it-works.
