# Graphiti / Zep

Access date: 2026-07-28.

1. Purpose: Graphiti is a temporal knowledge graph for agent memory; Zep is hosted enterprise memory.
2. License/distribution: Graphiti OSS, Zep managed platform.
3. Architecture: temporal fact graph, stale-fact invalidation, hybrid retrieval.
4. Modules: graph construction, fact storage, vector/full-text/graph retrieval, SDKs, governance.
5. Memory model: temporal context graph with nodes, edges, facts, and history.
6. Persona/style model: relationship/fact representation; not a texting style compiler.
7. Retrieval: hybrid vector, full-text, and graph traversal.
8. Prompt construction: Zep assembles context; app owns final behavior prompt.
9. Feedback/training: can ingest changing facts; feedback taxonomy must be app-defined.
10. Telegram/channel integration: none found.
11. Human behavior simulation: none.
12. Sales/support: supports business context, not workflow core.
13. Multi-user/multi-tenant: enterprise positioning.
14. Privacy/deployment: Graphiti self-hosted; Zep managed/compliance claims.
15. Strengths: best fit for temporal relationship memory.
16. Weaknesses: no behavior runtime.
17. Reusable: relationship memory substrate.
18. Not reusable: Telegram humanization.
19. Maturity: credible and actively documented.
20. Sources: https://github.com/getzep/graphiti, https://www.getzep.com/platform/graphiti/, https://help.getzep.com/graphiti/getting-started/overview, https://help.getzep.com/concepts, https://arxiv.org/html/2501.13956v1.
