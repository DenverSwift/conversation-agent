# LangMem

Access date: 2026-07-28.

1. Purpose: LangChain/LangGraph memory SDK for agents that learn from interactions.
2. License/distribution: open-source repository; verify exact license before adoption.
3. Architecture: functional memory primitives plus LangGraph storage integration.
4. Modules: memory extraction, prompt optimization, namespaced storage, LangGraph integration.
5. Memory model: long-term memories extracted and consolidated from conversation state.
6. Persona/style model: procedural prompt improvement is relevant; Matvey-style evidence compiler is not included.
7. Retrieval: storage-backed memory retrieval.
8. Prompt construction: memories and optimized prompts can be injected into agent context.
9. Feedback/training: feedback can guide memory and prompt updates.
10. Telegram/channel integration: none found.
11. Human behavior simulation: none.
12. Sales/support: none.
13. Multi-user/multi-tenant: namespaces support separation by user/team.
14. Privacy/deployment: self-hostable with chosen storage.
15. Strengths: strong memory extraction and prompt evolution concepts.
16. Weaknesses: no Telegram behavior runtime.
17. Reusable: memory extraction/update patterns.
18. Not reusable: complete communication platform.
19. Maturity: active ecosystem project.
20. Sources: https://github.com/langchain-ai/langmem, https://langchain-ai.github.io/langmem/, https://docs.langchain.com/oss/python/concepts/memory.
