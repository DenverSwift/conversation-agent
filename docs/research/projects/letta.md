# Letta / MemGPT

Access date: 2026-07-28.

1. Purpose: platform for stateful agents with advanced memory.
2. License/distribution: open-source harness plus hosted/service ecosystem.
3. Architecture: agent harness, SDK, tools, server/API, memory systems.
4. Modules: agent runtime, memory, tools, SDK, server, channels.
5. Memory model: advanced memory tiers and agent-managed memory updates.
6. Persona/style model: persistent agent identity; no ready Matvey evidence compiler.
7. Retrieval: memory retrieval across stored context.
8. Prompt construction: harness composes context from memory/tools.
9. Feedback/training: agents can learn over time.
10. Telegram/channel integration: core is channel-agnostic; LettaBot provided bot integration and is archived.
11. Human behavior simulation: not Telegram-focused.
12. Sales/support: not primary.
13. Multi-user/multi-tenant: possible through platform deployment.
14. Privacy/deployment: local and hosted paths.
15. Strengths: strong stateful-agent architecture.
16. Weaknesses: broad adoption may overtake custom runtime.
17. Reusable: memory concepts and possible SDK pieces.
18. Not reusable: Telegram behavior policy as-is.
19. Maturity: active core; LettaBot archived.
20. Sources: https://github.com/letta-ai/letta, https://docs.letta.com/, https://docs.letta.com/v1-sdk/, https://github.com/letta-ai/lettabot.
