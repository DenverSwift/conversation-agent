# soul.md / SoulSpec

Access date: 2026-07-28.

1. Purpose: portable persona/identity documents for agents.
2. License/distribution: public websites and open-source templates/spec materials.
3. Architecture: file-based persona and identity descriptions.
4. Modules: Markdown persona files, identity anchors, boundaries, template/spec guidance.
5. Memory model: persistent file memory, not database memory.
6. Persona/style model: strong persona packaging.
7. Retrieval: none by default.
8. Prompt construction: persona text supplied as instructions.
9. Feedback/training: manual edits or agent-managed file updates.
10. Telegram/channel integration: none.
11. Human behavior simulation: only through instructions.
12. Sales/support: none.
13. Multi-user/multi-tenant: portable files can be scoped manually.
14. Privacy/deployment: simple local files.
15. Strengths: excellent low-tech identity model.
16. Weaknesses: not enough for evidence retrieval or behavior timing.
17. Reusable: persona document conventions.
18. Not reusable: runtime engine.
19. Maturity: emerging pattern, not platform.
20. Sources: https://soul.md/, https://github.com/re-marked/soul, https://soulspec.org/.
